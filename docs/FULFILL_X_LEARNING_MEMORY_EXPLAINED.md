## 1. Deliberate Learning & Memory Architecture
- **Episodic Memory Bank**: Stores past disruption scenarios, agent proposal trade-offs, and actual execution outcomes.
- **Challenger Model Lifecycle**: Evaluates new agent reasoning candidates against historical baseline models.
- **Promotion Threshold**: A challenger model must demonstrate >= 2.0% improvement in resilience score over 5 evaluation runs to achieve promotion.
