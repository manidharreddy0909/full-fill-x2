# FULFILL-X — FRONTEND ARCHITECTURE EXPLAINED

> **Location**: `frontend/src/`  

---

## 1. Tech Stack Overview
- **Core**: React 18 + TypeScript + Vite 5
- **Styling**: Vanilla CSS (`index.css`) + Tailwind CSS + Radix UI primitives
- **3D Graphics**: React Three Fiber (R3F) + Three.js + Drei
- **State Management**: Zustand stores (`useResilienceStore`, `useCockpitStore`, `useTwinStore`, `useAgentStore`)
- **Data Fetching**: TanStack React Query (`queryClient`)
- **Routing**: React Router v6 (`App.tsx`)
