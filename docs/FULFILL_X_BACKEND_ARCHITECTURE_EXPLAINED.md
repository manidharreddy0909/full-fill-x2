## 1. Tech Stack Overview
- **Framework**: Python 3.12 + FastAPI + Uvicorn
- **Validation**: Pydantic v2 schemas
- **Graph Processing**: NetworkX + PyTorch/Scikit GNN
- **Realtime**: WebSockets (`WebSocketManager`)
- **Async Runtime**: asyncio + AnyIO
- **Testing**: Pytest + pytest-asyncio (249 tests passing)
